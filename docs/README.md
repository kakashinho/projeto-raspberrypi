# 📚 Documentação

Arquivos de apoio do projeto: materiais, ligações elétricas, a transferência para quem vai seguir o projeto e as evidências do protótipo.

## 📂 O que tem aqui

| Arquivo ou pasta | Para que serve |
| :-- | :-- |
| `transferencia.md` | Guia de entrega: o que tem no repositório e como usar cada parte |
| `lista_de_materiais.csv` | Componentes da placa, com quantidade e referência |
| `ligacoes_netlist.csv` | Ligações elétricas da placa, pino a pino |
| `projeto_fisico/` | Fotos da bancada e do protótipo, e o vídeo de demonstração |
| `imagens/` | Imagens usadas no README principal (por exemplo, a captura do painel) |
